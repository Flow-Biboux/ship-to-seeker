## Description

Ship to Seeker is a companion app for developers building Solana Mobile dApps. Diagnostics runs green-or-red checks on the phone you ship to: devnet RPC, wallet connection through Mobile Wallet Adapter, a devnet transaction and the Seeker Genesis Token, each with a plain-English fix. Build Path takes you from an empty folder to a dApp Store release in seven short modules. Explainer turns a pasted error into what it means and how to fix it. Free and open source, built in public at clock-in.biboux.com.
